# Metric English V1.3：60天进阶阅读扩充版验收文档

## 已确认范围

- 新增30篇原创数据分析英文阅读，总量从10篇增加到40篇。
- 现有10篇作为基础阅读保留，新文章编号为11至40。
- 每篇文章训练2天，依次为精读日和应用日，共形成60天计划。
- 训练按完成顺序推进，不按自然日期跳过。
- 新文章从B1逐步提升到B2，篇幅约300至650个英文词。
- 内容分为SQL与数据建模、指标与产品分析、实验与统计、报告与沟通、数据质量与治理、策略与管理层表达6个模块，每个模块5篇。
- 每篇文章继续包含English Original、Chinese Translation、Vocabulary、Grammar Analysis、Data Analyst Extension、Reading Questions六个必需部分。
- 新增主题、难度、完成状态筛选及40篇总进度。
- 本地数据升级到schema 4，完整保留V1.1阅读和V1.2写作进度。

## B1：实体生命周期

### 实体：阅读文章

生命周期：清单登记 → 加载成功 → 可学习

牵连关系：

- 文章`id`与资料库完成状态、进阶阅读训练记录、最后阅读位置关联，上线后不得修改已有`id`。
- Markdown缺少任一必需部分或加载失败时，文章进入不可完成状态，用户可重试，既有进度不改变。
- 已被训练记录引用的文章不得直接从清单删除；即使内容下架，也要保留稳定`id`和可解释的占位状态。

### 实体：进阶阅读计划

生命周期：未开始 → 进行中 → 60天完成

牵连关系：

- 用户开始第1天时创建计划开始时间，但当前训练日始终由第一个未完成记录推导。
- 当前日完成后解锁下一日，不因跨自然日、切换设备或长时间中断而跳题。
- 第60天完成后写入完成时间，停止解锁新任务，但文章和记录仍可查看。
- V1.1基础阅读、V1.2职场写作、V1.3进阶阅读分别统计进度与连续学习信号。

### 实体：文章训练记录

生命周期：未解锁 → 精读日可用 → 精读日完成 → 应用日可用 → 文章完成

牵连关系：

- 精读日4项任务全部完成后，应用日才可用。
- 应用日4项任务全部完成后，文章进入完成状态并解锁下一篇。
- 文章训练完成后自动加入资料库已完成状态。
- 从资料库手动标记已读只改变资料库状态，不直接跳过进阶阅读计划。

精读日任务：

1. 不看翻译阅读英文原文。
2. 学习重点词汇。
3. 阅读语法解析。
4. 完成理解问题。

应用日任务：

1. 重新阅读并核对中文翻译。
2. 学习Data Analyst Extension。
3. 用英文口头复述文章。
4. 完成一项英文业务应用回答。

### 实体：每日任务记录

生命周期：未开始 → 部分完成 → 完成

牵连关系：

- 每日4项任务逐项保存，刷新页面后恢复。
- 只有4项全部完成才设置当天完成时间并推动计划。
- 已完成记录可查看，不通过普通操作回退为未完成。

### 实体：应用日英文回答

生命周期：空白 → 编辑中 → 达到最低词数 → 随应用日完成归档

牵连关系：

- 每篇进阶文章的应用日保存一段40至80词英文回答，最长3000字符。
- 回答每次修改后自动保存，页面隐藏或关闭前补充保存。
- 回答少于40个英文词时，应用日第4项任务不能完成。
- 回答只按纯文本渲染，不通过`innerHTML`插入页面。
- 重置V1.3进阶阅读时删除这些回答；普通资料库已读状态和词汇记录不受影响。

### 实体：阅读位置与词汇记录

阅读位置生命周期：无记录 → 保存栏目、双语状态、字号和滚动位置 → 再次打开时恢复

词汇记录生命周期：未掌握 → 标记掌握

牵连关系：

- 阅读位置继续使用现有`lastReader`数据，不因进入进阶计划而清空。
- 词汇继续使用现有`learnedWords`集合，同一词只保存一次。
- 文章更新或计划完成不删除阅读位置和词汇记录。

### 实体：本地进度与备份文件

生命周期：schema 1、2或3 → 校验 → 迁移为schema 4 → 保存

牵连关系：

- 迁移完整保留原10篇完成状态、旧30天记录、阅读位置、词汇和V1.2写作记录。
- 导入文件必须先完整校验，只有校验成功后才能替换当前本地数据。
- 无效、超限或结构冲突的文件被拒绝，当前数据保持不变。

## B2：五个必问

### Q1：空状态

- schema 4迁移完成但尚未开始时，显示60天计划介绍、6个主题模块和开始训练按钮。
- 阅读清单尚未加载时，开始按钮禁用并显示正在加载。
- 清单为空或格式错误时，显示加载失败和重新加载入口，不创建训练记录。
- 60天完成后显示完成状态、40篇总进度和复习入口，不再生成第61天。

### Q2：操作失败

1. 阅读目录请求失败：显示阅读目录加载失败并允许重试；保留现有阅读位置、任务和词汇记录。
2. Markdown加载失败或缺少必需部分：显示具体文章加载失败；禁止完成当天任务；重试后仍进入原训练日。
3. 浏览器本地存储不可用或空间不足：显示进度保存失败；本次操作回退到上一次成功保存状态，界面不得显示虚假的已完成状态。
4. 导入文件无效、超限或schema不支持：覆盖数据前完成全部校验；校验失败只显示错误，当前数据不改变。
5. 复制英文回答或复述提示失败：保留可手动选择的纯文本并提示手动复制，不影响训练完成。

### Q3：数据被引用

- 训练记录通过文章`id`关联清单，不依赖数组位置，清单排序调整不影响进度。
- 已上线文章不得修改`id`；内容修订保留原训练记录。
- 删除文章时必须保留占位清单项，否则已有记录无法解释。
- 阅读完成状态同时被资料库卡片、总进度和训练首页使用，更新后统一重新渲染。
- 所有阅读记录只保存在当前浏览器，不上传文章回答、进度或公司信息。

### Q4：并发

- 同一浏览器打开多个标签页时，监听本地存储变化，并载入最近一次成功保存的数据。
- 标签页发现外部更新后刷新任务状态和进度，避免旧页面继续覆盖新数据。
- 两台电脑之间不自动同步；JSON导入采用完整替换，不做自动合并。
- 导入前显示文件版本、完成天数和更新时间，用户确认后才覆盖当前数据。

### Q5：后悔与撤销

- 当天尚未完成时，4项任务可以自由勾选或取消。
- 4项全部完成并解锁下一天后，该日记录不可单独撤销，避免后续进度出现断层。
- 资料库中的手动已读标记可以取消，但不影响60天训练状态。
- 提供重置V1.3进阶阅读入口，二次确认后只删除进阶阅读计划和训练记录。
- 重置不删除V1.1记录、V1.2写作、词汇和阅读位置。
- JSON导入属于覆盖操作，执行前要求确认并提示先导出当前进度。

## B3：输入输出链

### 输入

- 阅读清单：必须包含1个学习框架、10篇基础文章和30篇进阶文章。数量、字段、`id`或路径不合规时拒绝整个清单并显示重试。
- 进阶文章Markdown：每篇必须包含English Original、Chinese Translation、Vocabulary、Grammar Analysis、Data Analyst Extension、Reading Questions六个二级标题，缺少任一部分时禁止完成训练。
- 文章模块字段：只接受`sql`、`metrics`、`experiments`、`communication`、`quality`、`strategy`六个值，非法值导致清单校验失败。
- 应用题：每篇进阶文章必须包含Workplace Application及参考要点，缺少时应用日不可开始。
- 英文业务回答：只接受纯文本，目标40至80词，最长3000字符；超限输入不保存，HTML按普通文字显示。
- schema 1、2、3进度：自动迁移，完整保留旧阅读、写作、词汇和位置记录，进阶阅读保持未开始。
- schema 4进度：逐项校验60天记录、回答和完成时间，超限或非法字段使用安全值或拒绝导入。
- 用户操作：阶段切换、任务勾选、筛选和导入导出都必须在保存成功后更新完成状态。

### schema 4新增结构

```text
activeProgram:
  readingFoundation | writing | readingAdvanced

advancedReadingProgram:
  startedAt
  completedAt
  attempts:
    day 1–60:
      articleId
      mode
      tasks
      applicationText
      startedAt
      updatedAt
      completedAt
```

迁移规则：

- 原`reading`映射为`readingFoundation`。
- 原`writing`继续映射为`writing`。
- 不强制把老用户切换到新阶段，阶段切换入口显示V1.3新内容提示。
- 当前进阶训练日由第一个未完成的attempt推导。

### 输出

- 首页：输出当前天数、文章、训练模式、完成进度和继续训练入口；清单未加载时禁用开始按钮。
- 资料库：输出40篇文章及模块、难度、完成状态筛选；窄屏使用单列卡片，列表区域独立滚动。
- 阅读器：输出文章六部分；Markdown只渲染允许的结构，用户文本不进入`innerHTML`。
- 应用回答区：输出实时词数、自动保存状态和回答文本；页面隐藏或关闭前补充保存。
- 本地存储：输出schema 4完整进度；保存失败回退到最近一次成功状态。
- JSON导出：包含V1.1、V1.2、V1.3进度，不包含文章正文。
- 训练统计：分别输出基础阅读、职场写作和进阶阅读的完成数与连续学习信号。
- 自动化测试：检查内容完整性、迁移、顺序推进和响应式布局，任一新文章缺少必需部分时测试失败。

应用日完成条件：

1. 核对中文翻译。
2. 阅读Data Analyst Extension。
3. 完成英文口头复述。
4. 英文业务应用回答达到至少40词。

## B4：子功能优先级

### 第一批优先实现

1. schema 4数据结构、旧数据迁移及导入导出兼容。
2. 基础阅读、职场写作、进阶阅读三阶段切换。
3. 30篇文章对应60天精读日、应用日的顺序状态机。
4. 应用日英文回答编辑器、实时词数和自动保存。

第一批完成时允许进阶文章正文尚未全部写入，但现有V1.1和V1.2功能必须保持可用。进阶清单不足30篇时，V1.3显示内容准备状态并禁止创建不完整训练记录；自动化测试使用固定的30篇安全测试清单验证60天状态机。

### 第二批必须实现

1. 新增30篇原创进阶文章及完整中文翻译。
2. 40篇阅读清单与严格字段、路径、章节校验。
3. Markdown失败重试、保存失败回退和跨标签页同步。
4. 用户回答纯文本渲染、长度限制和HTML注入防护。
5. Edge、键盘操作、焦点状态和移动端响应式适配。
6. 内容完整性、迁移、进度、失败恢复和多视口测试。

### 应该随V1.3实现

1. 按6个主题模块、难度和完成状态筛选。
2. 首页显示当前模块、文章、训练模式和60天进度。
3. 提供只重置V1.3进阶阅读的二次确认入口。
4. 阶段切换显示V1.3新内容标识及40篇总完成进度。

### 延后处理

- AI批改和自动能力评分。
- 语音识别与口语录音。
- 登录、云同步和多设备自动合并。
- 自动生成文章或接入第三方内容接口。
- 个性化难度算法和自由选天。
- 单词卡间隔复习系统。

## B5：验收标准

### AC-1：schema 4默认结构

- 前置：浏览器没有旧进度。
- 操作：首次打开网站。
- 期望：本地数据保存为schema 4；包含`advancedReadingProgram.startedAt`、`completedAt`和`attempts`；默认值分别为`null`、`null`和空对象。
- 关联子功能：schema 4数据结构。

### AC-2：旧数据迁移

- 前置：分别准备schema 1、2、3进度。
- 操作：加载网站或导入进度。
- 期望：迁移为schema 4；原阅读完成记录、日期任务、词汇、阅读位置和全部写作记录保持一致；进阶阅读为空白未开始。
- 关联子功能：旧数据迁移。

### AC-3：三阶段切换

- 前置：清单加载完成。
- 操作：依次切换基础阅读、职场写作、进阶阅读。
- 期望：首页标题、进度、任务入口和统计切换到对应阶段；刷新后仍停留在最近选择的阶段；三个阶段的数据互不修改。
- 关联子功能：三阶段切换。

### AC-4：进阶内容未准备状态

- 前置：进阶清单少于30篇或字段校验失败。
- 操作：切换到进阶阅读。
- 期望：显示内容准备中和重试入口；开始按钮禁用；`attempts`保持为空；基础阅读和职场写作仍可正常使用。
- 关联子功能：三阶段切换、60天状态机。

### AC-5：60天映射

- 前置：加载30篇合规测试文章。
- 操作：读取第1、2、3、59、60天计划。
- 期望：第1和第2天对应第1篇；第3天对应第2篇；第59和第60天对应第30篇；奇数日为精读日，偶数日为应用日。
- 关联子功能：60天状态机。

### AC-6：按完成顺序推进

- 前置：当前为第1天。
- 操作：跨自然日、刷新页面或关闭后重新打开。
- 期望：未完成时仍停留第1天；完成第1天后进入第2天；当前天数始终由第一个未完成记录推导。
- 关联子功能：60天状态机。

### AC-7：精读日完成

- 前置：进入奇数日精读训练。
- 操作：逐项完成4项任务。
- 期望：任务状态每次操作后保存；4项未全部完成时不能进入下一天；全部完成后写入`completedAt`并解锁应用日；已完成记录不可单独撤销。
- 关联子功能：60天状态机。

### AC-8：应用回答编辑器

- 前置：进入偶数日应用训练。
- 操作：输入英文回答。
- 期望：显示实时英文词数；400毫秒防抖保存；刷新后恢复；页面隐藏或关闭前补充保存；最多保存3000字符。
- 关联子功能：应用回答编辑器。

### AC-9：应用日完成

- 前置：进入应用日。
- 操作：完成翻译核对、分析师扩展和口头复述，并输入英文回答。
- 期望：回答少于40词时禁止完成并显示还需多少词；达到40词后第4项自动满足；全部条件完成后解锁下一篇；超过80词只提示超出建议范围，不阻止完成。
- 关联子功能：应用回答编辑器、60天状态机。

### AC-10：用户文本安全

- 前置：在回答框输入`<img src=x onerror=alert(1)>`等HTML。
- 操作：保存、刷新并查看记录。
- 期望：内容以普通文本显示；不创建图片节点、不执行事件、不写入`innerHTML`。
- 关联子功能：应用回答编辑器。

### AC-11：保存失败回退

- 前置：模拟`localStorage.setItem`抛出异常。
- 操作：勾选任务或修改回答。
- 期望：显示保存失败；完成状态回退到最近成功保存的数据；不能错误解锁下一天。
- 关联子功能：schema 4数据结构、60天状态机、应用回答编辑器。

### AC-12：自动化回归

- 前置：完成首批代码。
- 操作：运行浏览器测试。
- 期望：覆盖schema迁移、三阶段隔离、60天映射、跨日期不跳题、回答恢复、40词门槛、纯文本防注入；原V1.1和V1.2测试继续通过。
- 关联子功能：首批全部功能。
