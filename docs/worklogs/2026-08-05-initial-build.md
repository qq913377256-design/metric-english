# 2026-08-05 初版开发日志

## 目标

构建一个可部署到GitHub Pages的纯前端个人英语阅读训练网站，面向词汇量约1000、希望提升数据分析工作英语的中文母语用户

## 关键决策

- 使用原生HTML、CSS、JavaScript和Markdown，不使用后端、构建工具或运行时第三方API
- 所有静态资源使用相对路径，兼容GitHub Pages项目子路径
- 学习进度、每日任务和词汇状态只保存在浏览器localStorage
- 《新概念英语》第三册仅提供原创学习框架，不复制教材课文或音频
- 首批10篇数据分析文章全部原创，难度从A2过渡到B2
- 界面采用分析师工作台和纸质阅读笔记的视觉方向，桌面端使用侧边资料库，窄屏使用抽屉导航

## 完成功能

- 今日35分钟计划、一年路线、连续学习与完成进度
- Markdown文章目录、异步加载、六部分内容切换和折叠答案
- 搜索、难度筛选、双语对照、字号调整、已读标记和词汇掌握记录
- GitHub Pages Actions部署流程、README和内容扩展说明
- Edge浏览器冒烟测试，覆盖核心阅读与持久化流程

## 验证结果

- manifest路径11/11有效
- 10篇文章共60个必需章节完整
- JavaScript语法检查通过
- Git差异空白检查通过
- Microsoft Edge无头模式完整交互测试通过

## 已知限制

- 直接使用file协议打开页面时，浏览器会拦截Markdown fetch；本地预览需要静态文件服务
- 学习记录不跨浏览器或设备同步，清除站点数据后无法恢复
- GitHub私人仓库的Pages可用性和站点访问范围取决于账户与组织设置
- 新概念英语教材原文、官方翻译和音频需要用户通过合法渠道另行获取
