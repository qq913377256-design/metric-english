# V1.3 阅读内容扩充开发记录

## 目标

- 把进阶阅读从核心引擎扩充为可学习的60天正式版本。
- 新增30篇原创数据分析英语文章，并保持V1.1、V1.2数据隔离。

## 关键实现

- `content/manifest.json`新增30条`track: advanced`记录，六个模块各5篇。
- 每篇文章包含六个固定章节、Workplace Application和Answer Key；公司与数据均为虚构。
- 资料库新增主题模块与完成状态筛选，并在卡片上显示模块。
- 应用日编辑器显示当前文章的业务题面；缺少题面或答案时禁止形成可完成训练。
- 新增只清除`advancedReadingProgram`的确认式重置，保留基础阅读、写作、词汇与资料库已读状态。
- V1.1每日计划显式只读取基础文章，避免新增内容改变原30天映射。

## 验证

- 清单共41项：1个框架、10篇基础文章、30篇进阶文章。
- 六个进阶模块均为5篇，全部包含必需章节、应用题和答案。
- 英文原文篇幅目标为300–650词，并使用本地脚本审计。
- 浏览器测试改为直接使用正式进阶清单，不再注入测试文章。
- Microsoft Edge无头全流程测试通过，包含模块/完成状态筛选、60天映射、应用回答、防注入、重置和多视口检查。

## 已知限制

- 进度仍只保存在当前浏览器；换电脑需要JSON导入导出。
- 自评与应用回答没有AI批改，训练结果用于自我复盘，不代表客观能力证明。
- 本批次不包含Git提交、推送或Pages部署。
