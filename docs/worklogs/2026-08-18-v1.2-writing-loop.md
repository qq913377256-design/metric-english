# V1.2 30天数据分析师英文写作训练开发记录

## 目标

- 在V1.1阅读训练之外增加独立的职场写作阶段
- 用10个数据分析工作情境形成30天示范、引导、独立输出闭环
- 保留首次提交，支持自评、参考对照、修改和基线终测比较
- 完整保留并迁移现有V1.1本地进度

## 关键决策

- V1.1和V1.2双阶段并存，升级后默认显示职场写作
- 写作内容按完成顺序推进，当前任务未完成时不会因日期变化跳题
- 每天首次提交和五项自评完成后计为完成；口头复述不阻塞进度
- 首次提交为不可覆盖快照，编辑器继续保存修改版
- 参考版本在首次提交和五项自评完成前隐藏
- 第1天和第30天使用同结构、不同数据的限时任务，只展示用时、字数和自评分变化
- 存储键继续使用metricEnglish.v1，schema升级到3，旧版阅读字段保持兼容
- 草稿、复盘和导入JSON都按长度、类型、枚举与日期格式收敛；用户文本只按纯文本显示
- 所有训练数据均为原创虚构内容，页面提醒不要粘贴公司机密

## 验收覆盖

- 10个写作情境和30天三日映射
- schema 2自动迁移到schema 3
- 草稿400毫秒防抖保存、刷新恢复和有效时间累计
- 首次提交不可覆盖，修改版单独保留
- 五项0到2分自评完成后解锁参考版本
- 材料加载失败时保留草稿、禁用提交并支持重试
- 恶意HTML草稿只显示为文本
- V1.1阅读任务、资料库、键盘切换和词汇记录回归
- 320×568至1440×960视口无页面级横向滚动

## 验证结果

- app.js和浏览器测试脚本语法检查通过
- 10份写作Markdown的必需章节检查通过
- Edge无头浏览器端到端测试通过
- schema迁移、顺序解锁、草稿恢复、快照保护、自评解锁、防注入和失败重试通过
- V1.1阅读回归、键盘切换、词汇状态和资料库数量检查通过
- 桌面双栏和390像素移动端写作训练台完成截图检查
- 静态资源继续使用相对路径，未引入运行时依赖、后端或密钥

## 已知限制

- 不提供AI批改、语音识别、账号、云同步或多设备自动合并
- 自评分只用于个人复盘，不等同于标准化英语能力测评
- 浏览器禁用localStorage或剪贴板权限时会降级提示，仍可手工复制文本
