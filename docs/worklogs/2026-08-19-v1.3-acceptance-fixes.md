# V1.3 验收问题修复记录

## 目标

- 按验收优先级修复进阶阅读内容支持和应用训练闭环。
- 保持schema 4和既有V1.1、V1.2进度兼容。

## 内容修订

- 第21–40篇三道阅读题改为独立Markdown列表项。
- 第31–40篇中文部分改为与英文段落对应的完整翻译。
- 第31–40篇重点词汇从4个增加到8个。
- 30篇应用任务均新增40–80词`Application Model Response`，理解题答案也统一为三项列表。

## 产品与前端

- “写作记录”入口统一为“训练记录”，进阶阶段显示60天阅读记录。
- 进阶记录按所属模块展示实际保存过的应用回答、字数、完成日期，并支持复制和重新打开；未作答和未解锁任务继续留在首页路线图，不挤占历史记录。
- 侧栏在桌面与窄屏断点之间切换时重置为关闭状态，避免横竖屏或窗口缩放后遮住正文。
- 理解题答案在精读日完成后解锁，应用参考版本在应用日完成后解锁。
- 进阶训练页面隐藏资料库“标记为已读”控件，避免与“完成训练日”混淆。
- 用户回答继续通过`textContent`和表单value渲染，不进入`innerHTML`。

## 验证结果

- 内容审计通过：30篇进阶文章均保留六个必需部分、3道独立问题、3条理解题答案和40–80词应用参考版本；第31–40篇各有8个重点词汇。
- Edge浏览器自动化通过：覆盖schema 1/2/3迁移、写作记录回归、60天映射、答案解锁、回答记录、保存失败回退和恶意HTML按纯文本显示。
- 320×568、390×844、667×375、768×1024、1024×768、1440×960视口无页面级横向滚动；390×844记录页截图复核通过。
- JavaScript语法、静态资源相对路径、HTML重复ID和Git空白错误检查通过。

## 已知限制

- 进阶回答仍不提供AI批改或客观评分。
- 记录保存在当前浏览器，跨设备仍需JSON导入导出。
