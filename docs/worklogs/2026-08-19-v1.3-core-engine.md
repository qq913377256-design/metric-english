# V1.3进阶阅读核心引擎工作日志

## 目标

优先实现schema 4、三阶段切换、60天顺序状态机和应用日英文回答编辑器。本批不写入30篇正式进阶文章。

## 关键决策

- 现有`metricEnglish.v1`存储键不变，数据升级到schema 4。
- 原`reading`阶段迁移为`readingFoundation`，新增`readingAdvanced`，原写作阶段保持`writing`。
- 进阶阅读必须恰好加载30篇按6个模块排序的合规内容后才能开始；不足时只显示内容准备状态，不创建训练记录。
- 60天按第一个未完成记录推导，奇数日为精读日，偶数日为应用日，不使用自然日期推进。
- 应用日回答最长3000字符，400毫秒防抖保存，页面隐藏或关闭前补充保存；达到40词后才满足完成条件，超过80词只提示。
- 用户回答只使用`textarea.value`和`textContent`处理，不作为HTML渲染。
- 任务或回答保存失败时保留最近成功数据，不解锁下一天。

## 实现范围

- schema 1、2、3到schema 4迁移与schema 4导入导出。
- 基础阅读、职场写作、进阶阅读三阶段切换。
- 30篇文章对应60天的精读日、应用日映射。
- 进阶阅读首页、6模块路线图、进度与连续学习信号。
- 阅读器下方的进阶任务面板、应用回答编辑器和完成门槛。
- 内容不足30篇时的安全降级状态。

- `node --check app.js`与`node --check tests/browser-smoke.js`通过。
- Edge浏览器自动化回归通过，输出`V1.3 core browser smoke test passed`。
- 覆盖schema 1、2、3迁移，V1.1阅读和V1.2写作回归通过。
- 覆盖第1、2、3、59、60天映射及跨自然日不跳题。
- 覆盖英文回答刷新恢复、40词门槛、恶意HTML纯文本显示和本地存储失败回退。
- 390×844移动端进阶首页无页面级横向滚动，关闭侧栏保持`inert`。
