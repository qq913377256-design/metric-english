# What Does a Dashboard Do?

## English Original

Mina works in the sales team of a small online shop. Every Monday, she opens a dashboard before the team meeting. The dashboard shows five important numbers: total sales, number of orders, average order value, new customers, and returned products.

The numbers do not only show what happened. They help Mina ask better questions. This week, total sales are higher than last week, but the number of orders is lower. Mina notices that the average order value went up. She checks the product table and finds that more customers bought an expensive coffee machine.

A useful dashboard makes changes easy to see. It also compares results with a target or an earlier period. It does not need twenty charts. It needs the right information for a decision. Mina uses the dashboard to tell the team where sales changed and what they should check next.

## Chinese Translation

Mina在一家小型网店的销售团队工作。每周一，她都会在团队会议前打开一个仪表盘。仪表盘显示五个重要数字：总销售额、订单数、平均订单金额、新客户数和退货商品数

这些数字不只展示发生了什么，还能帮助Mina提出更好的问题。本周总销售额高于上周，但订单数更少。Mina注意到平均订单金额上升了。她查看商品表，发现购买高价咖啡机的客户变多了

有用的仪表盘能让变化一眼可见，也会把结果与目标或之前的时间段比较。它不需要二十张图表，只需要提供决策所需的正确信息。Mina用仪表盘告诉团队销售变化出现在哪里，以及下一步应该检查什么

## Vocabulary

- **dashboard** /ˈdæʃbɔːrd/：仪表盘，用一组指标和图表呈现业务状态
- **total sales**：总销售额，某段时间内全部销售金额
- **order** /ˈɔːrdər/：订单
- **average order value**：平均订单金额，常缩写为AOV
- **return** /rɪˈtɜːrn/：退回、退货
- **notice** /ˈnoʊtɪs/：注意到某个变化
- **compare** /kəmˈper/：比较
- **target** /ˈtɑːrɡɪt/：目标值

## Grammar Analysis

### 1. 比较级

`Total sales are higher than last week, but the number of orders is lower.`

`higher than`表示高于，`lower`省略了重复的比较对象。`but`连接两个方向不同的变化

可替换为：`Conversion is higher than last month, but traffic is lower.`

### 2. 宾语从句

`She finds that more customers bought an expensive coffee machine.`

`that`引出Mina发现的具体内容。工作汇报中可以用`We found that...`陈述分析发现

## Data Analyst Extension

基础仪表盘通常回答三个问题：现在是多少、和什么相比、是否需要行动。介绍指标时可以使用以下句型：

- `Sales increased from 80,000 yuan to 95,000 yuan.`
- `The result is 5% above our weekly target.`
- `Order volume fell, while average order value increased.`
- `We should check the product mix next.`

练习：从你熟悉的工作中选择三个指标，用`current value + comparison + next check`各写一句

## Reading Questions

1. Which five numbers does Mina's dashboard show?
2. Why did total sales rise when the number of orders fell?
3. What makes a dashboard useful?
4. Which three metrics would you put on a dashboard for your work?

### Answer Key

1. It shows total sales, order count, average order value, new customers, and returned products
2. More customers bought an expensive coffee machine, so the average order value increased
3. It makes changes clear, provides a useful comparison, and supports a decision
4. Sample answer: I would use active users, conversion rate, and revenue
